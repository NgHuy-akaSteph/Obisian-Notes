

| CÚ PHÁP                     | Ý NGHĨA                                                                                                                                           |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| pwd                         | Kiểm tra xem đang ở thư mục nào                                                                                                                   |
| whoami                      | Kiểm tra user đang sử dụng phiên                                                                                                                  |
| cd + đường dẫn              | Di chuyển đến thư mục tương ứng. Nếu đường dẫn là .. thì sẽ di chuyển quay lại thư mục cha                                                        |
| ls + đường dẫn              | Xem nội dung thư mục tương ứng. Option -l: hiển thị dạng danh sách, Option -a: hiển thị file và thư mục ẩn, Option -t: sắp xếp theo thời gian tạo |
| mkdir + tên thư mục         | Tạo thư mục mới. Option -p cho phép tạo nhiều thư mục theo đường dẫn chỉ định (tạo nhiều thư mục mới lồng nhau)                                   |
| touch + đường dẫn           | Tạo file mới                                                                                                                                      |
| rm + đường dẫn              | Xóa file vừa tạo. Nếu có option -r thì sẽ xóa được thư mục. Nếu có option -rm thì xóa không cần xác nhận (buộc xóa)                               |
| cp source target            | Copy file từ source -> target. Nếu có thêm option -r thì có thể copy được thư mục                                                                 |
| mv source target            | Di chuyển file từ source -> target (nếu muốn đổi tên thì cứ thay luôn tên mới vào target)                                                         |
| echo "nội dung"             | In nội dung ra màn hình                                                                                                                           |
| echo "nội dung" > đường dẫn | Ghi nội dung ra file tương ứng. Nếu muốn ghi thêm dòng dưới thì thêm > (ví dụ dòng 2 là >>)                                                       |
| cat + đường dẫn             | Xem nội dung file                                                                                                                                 |
| history                     | Xem lịch sử câu lệnh đã gõ                                                                                                                        |
| tail + đường dẫn            | Xem nội dung trong file. Option -n + số dòng muốn xem (tính từ cuối). Option -f thì xem dữ liệu realtime (Ctrl + C để ngắt)                       |
| sudo + lệnh                 | Thực hiện câu lệnh với quyền Admin                                                                                                                |
![[linux-system-files.png]]
* Tự động hoàn thiện câu lệnh:
	* Gõ một phần lệnh ví dụ: ls /va + Tab -> ls /var/
	* Nếu gõ ls /var/lo + Tab -> 0 thay đổi -> có nhiều folder cùng có chữ 'lo'. Khi đó chỉ cần gõ Tab lần nữa sẽ hiển thị toàn bộ folder chứa 'lo'
- Nhấn mũi tên lên/ xuống để trở lại các lệnh đã gõ
- Dấu . là đại diện cho thư mục hiện tại
