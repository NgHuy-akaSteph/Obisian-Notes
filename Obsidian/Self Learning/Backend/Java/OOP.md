1. Framework for OOD interview
	1. Requirements Gathering:
		1. Analyzing the problem statement and identifying key functional and non-functional requirements
		2. Ask targeted questions to resolve ambiguities, establish realistic contrainsts, and confirm an assumptions. -> share a clear understanding of scope and priorities.
	2. Identify Core Objects
		1. Select a primary use case and walk through it step-by-step to identify core objects and their interactions.
		2. A practical approach: map nouns in requirements to objects and verbs to methods.
	3. Design Class Diagram and Code
		1. Using either a top-down or bottom-up appoarch: 
			1. Top-down: identify high-level components or parrent classes, then refine their attributes and methods.
			2. Bottom-up: Define concrete classes first (attributes, method) and build relationship from there.
