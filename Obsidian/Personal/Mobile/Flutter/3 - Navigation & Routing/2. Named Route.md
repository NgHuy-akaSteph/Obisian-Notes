### 1. Cách dùng

- Cơ chế: Mỗi màn hình sẽ có một tên riêng và sẽ sử dụng làm định vị để chuyển đến màn hình đó.
- B1: Định nghĩa route ở `MaterialApp()`:
```dart
MaterialApp(
  // Định nghĩa bảng tên
  routes: {
    '/': (context) => const HomeScreen(),      // Trang chủ
    '/second': (context) => const SecondScreen(), // Màn hình 2
  },
  initialRoute: '/', // Chạy trang này đầu tiên
);
```
- B2: Sử dụng 
```dart
// Within screen 1: đến trang thứ 2
Navigator.pushNamed(context, '/second');

// Within screen 2: quay về trang trước
Navigator.pop(context);
```

### 2. Điểm hạn chế

- Truyền dữ liệu giữa các màn hình hơi khó và thiếu an toàn
```dart
// người gửi
Navigator.pushNamed(
  context, 
  '/second', 
  arguments: "Xin chào" // Truyền đi một Object (bất cứ cái gì)
);

// Người nhận phải ép kiểu thủ công
// Bên trong SecondScreen
@override
Widget build(BuildContext context) {
  // Phải ép kiểu 'as String'. Nếu bên kia lỡ truyền số 10 -> Crash App ngay lập tức!
  final args = ModalRoute.of(context)!.settings.arguments as String; 

  return Text(args);
}
```

- Không hỗ trợ Deep Linking tốt (URL động): Muốn sử dụng **myapp://product/123** thì sẽ không hiểu được **123** là **id**
```dart
routes: {
  '/product': (context) => ProductScreen(), // Chỉ hiểu /product
}
```

- Khó khăn trong việc refactoring: Khi thay named route và IDE không tự động sửa.
