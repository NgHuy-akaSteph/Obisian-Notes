## 1. Hệ thống Phím tắt Tìm kiếm (Search)
Đây là nhóm phím quan trọng nhất để hạn chế dùng chuột.

| Chức năng                           | macOS                  | Windows/Linux                  |
| :---------------------------------- | :--------------------- | :----------------------------- |
| **Search Everywhere** (Tìm mọi thứ) | `Shift` + `Shift`      | `Shift` + `Shift`              |
| **Find Action** (Tìm lệnh/cài đặt)  | `Cmd` + `Shift` + `A`  | `Ctrl` + `Shift` + `A`         |
| **Find File** (Tìm tên file)        | `Cmd` + `Shift` + `O`  | `Ctrl` + `Shift` + `N`         |
| **Find Symbol** (Hàm, biến, class)  | `Cmd` + `Option` + `O` | `Ctrl` + `Alt` + `Shift` + `N` |
| **Find Class** (Tìm lớp)            | `Cmd` + `O`            | `Ctrl` + `N`                   |
|                                     |                        |                                |

## 2. Điều hướng và Chỉnh sửa Code (Editing)

| Chức năng                                | macOS                       | Windows/Linux                |
| :--------------------------------------- | :-------------------------- | :--------------------------- |
| **File Structure** (Cấu trúc file)       | `Cmd` + `F12`               | `Ctrl` + `F12`               |
| **Expand Selection** (Mở rộng vùng chọn) | `Option` + `Up`             | `Ctrl` + `W`                 |
| **Shrink Selection** (Thu nhỏ vùng chọn) | `Option` + `Down`           | `Ctrl` + `Shift` + `W`       |
| **Move Line Up/Down** (Di chuyển dòng)   | `Cmd` + `Shift` + `Up/Down` | `Ctrl` + `Shift` + `Up/Down` |
| **Duplicate Line** (Nhân bản dòng)       | `Cmd` + `D`                 | `Ctrl` + `D`                 |
| **Recent Files** (File vừa mở)           | `Cmd` + `E`                 | `Ctrl` + `E`                 |
| **Quay về Editor** (Từ cửa sổ tool)      | `Esc`                       | `Esc`                        |

## 3. Các tính năng nâng cao "Pro"

### 📂 Quản lý Project View
* **Autoscroll to Source:** Bật tính năng *Open Files with Single Click* và *Always Select Opened File* (biểu tượng bánh răng ở cửa sổ Project) để IDE tự động highlight file đang mở trên cây thư mục.

* **Mở nhanh thư mục:** Dùng `Cmd + Up` (Mac) hoặc `Alt + Home` (Win) để điều hướng nhanh qua các folder cha.

### 💉 Inject Language
* Nhấn `Alt + Enter` khi đang ở trong một chuỗi String.
* Chọn **Inject Language/Reference** để IDE hỗ trợ highlight cú pháp (ví dụ CSS trong JS, SQL trong Java).
