Dưới đây là danh sách các tổ hợp phím tắt phổ biến và hữu ích nhất trong IntelliJ IDEA hỗ trợ cho việc di chuyển, sao chép và bôi đen code.

---

## 1. Phím Tắt Di Chuyển (Navigation)

| Chức năng                              | Phím tắt (Windows/Linux)                   | Mô tả chi tiết                                                     |
| :------------------------------------- | :----------------------------------------- | :----------------------------------------------------------------- |
| **Nhảy đến dòng**                      | `Ctrl + G`                                 | Nhập số dòng để di chuyển con trỏ ngay lập tức                     |
| **Di chuyển giữa các method**          | `Alt + Up` / `Alt + Down`                  | Nhảy đến phương thức (method/function) phía trên hoặc phía dưới    |
| **Chuyển Tab code**                    | `Alt + Left` / `Alt + Right`               | Di chuyển qua lại giữa các tab file đang mở                        |
| **Quay lại / Tiến tới vị trí con trỏ** | `Ctrl + Alt + Left` / `Ctrl + Alt + Right` | Quay lại (Back) hoặc tiến tới (Forward) vị trí con trỏ trước đó    |
| **Danh sách File vừa mở**              | `Ctrl + E`                                 | Hiển thị bảng chọn các file làm việc gần đây (*Recent Files*)      |
| **Tìm kiếm toàn cục**                  | `Shift` (nhấn 2 lần)                       | *Search Everywhere* - Tìm kiếm Class, File, Symbol hoặc Action     |
| **Đi tới Khai báo / Triển khai**       | `Ctrl + B`/`Ctrl + Alt + B`                | Nhảy đến nơi định nghĩa/triển khai của Class, Method hoặc Variable |
| **Đi tới Class**                       | `Ctrl + N`                                 | Tìm và mở nhanh một Class                                          |
| **Đi tới File**                        | `Ctrl + Shift + N`                         | Tìm và mở nhanh bất kỳ file nào trong dự án                        |

## 2. Phím Tắt Sao Chép & Xử Lý Dòng (Copy & Line Actions)

| Chức năng | Phím tắt (Windows/Linux) | Mô tả chi tiết |
| :--- | :--- | :--- |
| **Nhân bản dòng / Vùng chọn** | `Ctrl + D` | *Duplicate Line/Selection* - Nhân bản dòng hiện tại hoặc đoạn code đang bôi đen |
| **Xóa dòng hiện tại** | `Ctrl + Y` (hoặc `Shift + Delete`) | Xóa nhanh dòng con trỏ đang đứng mà không cần bôi đen |
| **Di chuyển dòng (Đơn giản)** | `Alt + Shift + Up` / `Down` | Dịch chuyển dòng hiện tại lên hoặc xuống |
| **Di chuyển Block / Method** | `Ctrl + Shift + Up` / `Down` | Dịch chuyển nguyên cả phương thức hoặc khối code hợp lệ lên/xuống |
| **Lịch sử Clipboard** | `Ctrl + Shift + V` | Mở cửa sổ xem lại danh sách các đoạn text đã copy gần đây |
| **Copy đường dẫn file / symbol** | `Ctrl + Shift + Alt + C` | Copy đường dẫn tuyệt đối hoặc reference của symbol |

## 3. Phím Tắt Bôi Đen & Chọn Code (Selection & Multi-cursor)

| Chức năng                             | Phím tắt (Windows/Linux)       | Mô tả chi tiết                                                                    |
| :------------------------------------ | :----------------------------- | :-------------------------------------------------------------------------------- |
| **Mở rộng vùng chọn (Smart Select)**  | `Ctrl + W`                     | Tăng dần phạm vi bôi đen theo ngữ pháp (Biến -> Dòng -> Khối code -> Hàm)         |
| **Thu nhỏ vùng chọn**                 | `Ctrl + Shift + W`             | Giảm dần phạm vi bôi đen đã chọn trước đó                                         |
| **Thêm con trỏ (Multi-cursor)**       | `Alt + Click`                  | Click chuột vào các vị trí khác nhau để gõ/sửa đồng thời                          |
| **Chọn từ con trỏ đến Đầu/Cuối dòng** | `Shift + Home` / `Shift + End` | Bôi đen nhanh từ vị trí hiện tại đến đầu hoặc cuối dòng                           |
| **Chọn tất cả từ trùng lặp**          | `Ctrl + Alt + Shift + J`       | Chọn toàn bộ các từ giống từ đang highlight trong file (*Select All Occurrences*) |
| **Chọn từ trùng lặp tiếp theo**       | `Alt + J`                      | Chọn thêm một từ trùng lặp tiếp theo (*Add Selection for Next Occurrence*)        |
| **Bỏ chọn từ trùng lặp gần nhất**     | `Alt + Shift + J`              | Hủy chọn vị trí từ vừa thêm gần nhất                                              |
