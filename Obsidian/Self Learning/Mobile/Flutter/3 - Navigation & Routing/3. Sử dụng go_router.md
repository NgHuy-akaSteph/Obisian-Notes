### B2: Xây dựng AppRouter và sử dụng

```dart
import 'package:flutter/material.dart';  
import 'package:flutter_scratch/widgets/navigation/fi_screen.dart';  
import 'package:flutter_scratch/widgets/navigation/not_found_screen.dart';  
import 'package:flutter_scratch/widgets/navigation/se_screen.dart';  
import 'package:go_router/go_router.dart';  
  
final GoRouter appRouter = GoRouter(  
    initialLocation: '/',  // trang bắt đầu
    debugLogDiagnostics: true, // Bật log để debug xem đi đâu về đâu  
    routes: <RouteBase>[  
      GoRoute(  
        path: '/',  
        name: 'first',  
        builder: (context, state) => const FirstScreen(),  
      ),  
      GoRoute(  
        path: '/second/:message',  
        name: 'second',  
        builder: (context, state) {  
          final String? message = state.pathParameters['message'];  
          return SecondScreen(message: message ?? '');  
        },  
      ),  
    ],  
  
    // Tạo thông báo lỗi đơn giản  
    // errorBuilder: (context, state) => Scaffold(    //   body: Center(child: Text('Lỗi: Không tìm thấy đường dẫn ${state.uri}'),),    // ),  
    // Tạo trang báo lỗi và custom hiệu ứng    errorPageBuilder:(context, state) {  
      return MaterialPage(  
        key: state.pageKey,  
        child: NotFoundScreen(error: state.error,)  
      );  
    }  
);
```

- GoRouter sử dụng cơ chế khai báo (declarative - Navigator 2.0) cho phép đồng bộ các trạng thái phức tạp khi điều hướng. GoRouter tự động quản lý Stack dựa trên config cho phép linh hoạt như URL trên trình duyệt, hỗ trợ tốt deep link. 

- Navigator cũ sử dụng chỉ định `(impretive)` - chỉ đâu làm đấy, tự quản lý ngăn xếp thủ công.

- Cách sử dụng điều hướng:
```dart
// Within first screen
onPressed: () {  
 context.push('/second/${Uri.encodeComponent(message)}');  
},


//Within second screen
onPressed: () {  
  // Gọi lệnh quay lại  
  context.pop();  
},
```

### B3: Truyền dữ liệu giữa các màn hình
#### C1: Truyền qua đường dẫn
- Dùng với dữ liệu là ID, chuỗi ngắn, số
- Router: định nghĩa bằng dấu `:`
```dart
GoRoute(
  path: '/details/:productId', // :productId là biến
  builder: (context, state) {
    // Lấy dữ liệu (Luôn là String)
    final id = state.pathParameters['productId']!;
    return DetailScreen(id: id);
  },
),
```
- Sender: nối trực tiếp chuỗi
```dart
context.push('/detail/123');

// Nếu có ký tự đặc biệt thì phải encode trước khi nối
// GoRouter sẽ tự decode nên không cần decode ở router
context.push('/details/${Uri.encodeComponent(biến_chuỗi)}');
```

#### C2: Sử dụng tham số truy vấn
- Dùng khi dữ liệu là các bộ lọc, tìm kiếm, tùy chọn không bắt buộc 
- Router: không cần định nghĩa gì đặc biệt trong path
```dart
GoRoute(
  path: '/search',
  builder: (context, state) {
    // Lấy dữ liệu từ sau dấu ?
    final query = state.uri.queryParameters['q']; 
    return SearchScreen(query: query);
  },
),
```
- Sender: dùng Uri tạo query
```dart
context.push(Uri(
  path: '/search',
  queryParameters: {'q': 'flutter', 'sort': 'new'},
).toString());
```

#### C3: Sử dụng `extra object` 
- Dùng khi muốn truyền cả một đối tượng mà không muốn ép kiểu sang String. Nhược điểm: Trên Web, nếu F5 (Refresh) thì dữ liệu bị mất (null).
- Router ép kiểu từ state.extra
```dart
GoRoute(
  path: '/profile',
  builder: (context, state) {
    // Ép kiểu về Class của bạn
    User user = state.extra as User; 
    return ProfileScreen(user: user);
  },
),
```
- Sender: dùng tham số `extra`:
```dart
User myUser = User(name: "Nam", age: 25);
context.push('/profile', extra: myUser);
```


### Lưu ý một số kiến thức:
- Chỉ có thể sử dụng 1 trong 2 cách báo lỗi `errorBuilder` hoặc `errorPageBuilder`
- Dùng `push()` và `pop()` nếu muốn qua màn hình khác vẫn có thể quay lại.
- Dùng `go()` nếu muốn chuyển hẳn sang tab khác và không quay lại.
